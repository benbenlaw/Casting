# Fluid Manager

## Fluid Manager

The Fluid Manager is a powerful tool that can be used to move fluids between Casting blocks. Using Shift and Scroll will go through avaible fluids that are stored on the Fluid Manager. To add fluids set the Fluid Mover to empty and right-click on the block, to remove set the fluid that you want to insert and right-click on the block. The fluid mover follows normal fluid restrictions apart from the mixer. The mixer can have its input removed with the Fluid Mover

The Fluid Mover only works with Casting blocks

### Troubleshooting
Not taking fluids? Make sure the Fluid Mover is set to Empty.
